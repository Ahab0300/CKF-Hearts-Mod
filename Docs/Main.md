# Hearts Mod Documentation

This **Hearts Mod** expands the content of `Cyber Knights:Flashpoint` by introducing evolving interpersonal relationships which
impact personnel management in the game. Events based on Hearts relationships can cause Stress and Hype, affect merc
availability, and lead to unpredicted interactions.
