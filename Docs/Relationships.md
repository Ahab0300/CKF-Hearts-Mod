# Relationships
**Hearts Mod** relies entirely on Relationship Tags. The base game supplies 47
relationships, and this mod adds 21 more relationships to flesh out the system.

The base game breaks relationships into three dimensions:

- 2 polarities (Likes and Dislikes)
- 5 categories (Personal, Romantic, Professional, Judgment, and Debt)
- 3 degrees (1, 2, and 3)

Not all of the combinations in the three dimensions are filled in the base game,
so **Hearts Mod** fills in the missing combinations.

Some of the relationships in the base game are closely tied to game events or
backstory. Examples include Revenge, Protective, Sibling, and Hunting.
**Hearts Mod** does not use these relationships. It is more appropriate that
a separate mod use these backstory relationships to generate storylines that
resolve any dangling plot threads.

One relationship, Grudge, is related to backstory but is used in **Hearts Mod**.
The only current Contact with the Grudge tag is B-Tuna. It is already possible
to change B-Tuna to a positive Trust during Ward War. For a long time, players
have expressed a desire to be able to patch relations with B-Tuna. Therefore,
**Hearts Mod** uses Grudge as the OwedDislikes-3 relationship. It will be
possible to improve the Relationship with B-Tuna.
